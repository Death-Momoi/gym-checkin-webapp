隱私權政策

本政策說明運動科學實驗室簽到系統如何處理使用者與 Google 資料。

最後更新：2026 年 9 月 25 日

1. 適用範圍

本政策適用於「運動科學實驗室簽到系統」（以下簡稱本系統）。 本系統為軟體工程課程專題，用於實驗室人員簽到、簽退、預約查詢及問題回報。

2. 我們處理的資料

Google 登入資料

使用 Google 登入時，本系統會處理 Google 帳號識別碼、姓名、 Email 與頭像，用來確認身分、建立個人資料並顯示操作人員。

簽到與回報資料

  • 簽到、簽退時間、使用身分、責任交接及設備檢查紀錄。
  • 協助簽退的操作人員與被協助人員。
  • 問題回報內容、處理狀態與通知結果。

Gmail 與 Google Calendar

  • Gmail 授權僅用於從指定的管理帳號寄出問題回報通知； 本系統不讀取、顯示或儲存信箱內容。
  • Google Calendar 授權用於讀取指定日曆的預約標題、開始時間與結束時間， 並顯示在預約查詢頁面。本系統不會新增、修改或刪除日曆活動。

3. 資料使用目的

  • 提供使用者驗證與維持登入狀態。
  • 執行簽到、簽退、在場查詢與紀錄查詢。
  • 顯示實驗室預約，並在收到問題時通知管理人員。
  • 維護系統安全、處理異常與改善服務。

4. 儲存、分享與保留

本系統使用 GitHub Pages 提供前端頁面，並使用 Supabase 提供驗證、 資料庫與後端功能。資料不會被販售，也不會用於廣告或不相關的行銷。 僅會在提供本系統功能所必要的範圍內，由 Google、Supabase 與 GitHub 等服務處理。

資料原則上保留至課程專題或實驗室管理需求結束；若不再需要， 管理人員可依請求刪除相關資料，但法律、資安或備份所必要的保留除外。

5. Google API 資料使用

本系統對從 Google API 取得資訊的使用與傳送，將遵守 Google API Services User Data Policy ，包含 Limited Use 要求。

6. 使用者選擇

使用者可登出本系統，或前往 Google 帳號的第三方連結管理頁面 撤銷授權。若需查詢、更正或刪除資料，請透過下方聯絡方式提出。

7. 聯絡方式

隱私權或資料處理相關問題，可透過 GitHub Issues 聯絡專案維護者。請勿在公開回報中張貼密碼、token 或其他敏感資料。
